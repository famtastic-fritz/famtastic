# SETUP — optional real services

**Lucid runs fully without any of this.** Out of the box it uses an offline
interpreter and disables voice transcription gracefully. This file is only for
when you want to upgrade those stubs to live providers later.

No account or key is required to use Lucid. Nothing here costs money unless you
choose to sign up for a provider yourself.

---

## 1. Create your `.env`

```bash
cp .env.example .env
```

Then edit `.env`. Leave any value blank to keep using the offline default.

---

## 2. Live AI interpretation (optional)

By default, dream interpretation is generated by the built-in offline
interpreter (`src/interpreter.js → localInterpret`). To route to a real LLM:

1. Get an API key from a provider you trust (e.g. Anthropic or OpenAI).
2. In `.env`:
   ```
   INTERPRETER_PROVIDER=anthropic
   INTERPRETER_API_KEY=sk-...your key...
   INTERPRETER_MODEL=claude-haiku-4-5-20251001
   ```
3. Implement the call inside `interpretWithProvider()` in
   `src/interpreter.js`. The seam is already there and clearly marked — you
   only fill in the `fetch` to your provider and return
   `{ source, body, themes, symbols }`. No UI or server changes needed.

If `INTERPRETER_PROVIDER` is set but the call isn't implemented yet, Lucid
falls back to the offline interpreter and labels the source so you can see the
provider was picked up.

---

## 3. Voice transcription (optional)

By default the mic records audio but there's no speech provider, so Lucid tells
you to type what you said. To enable real voice → text:

1. Get a speech-to-text API key.
2. In `.env`:
   ```
   TRANSCRIBER_PROVIDER=whisper
   TRANSCRIBER_API_KEY=...your key...
   ```
3. Implement the call inside `transcribeWithProvider()` in
   `src/transcriber.js` and return `{ ok: true, text: "..." }`.

---

## 4. Change the port

```
PORT=4317
```

Default is `4317`.

---

That's the entire surface. Everything else is local and free.
